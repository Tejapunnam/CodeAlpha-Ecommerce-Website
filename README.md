# 🛒 CodeAlpha E-Commerce Website

A fully functional **E-Commerce Website** built using **Django** as part of the **CodeAlpha Python Development Internship**.

This project demonstrates the implementation of user authentication, product management, shopping cart functionality, and checkout features in a responsive web application.

---

## 🚀 Live Demo

🌐 https://codealpha-ecommerce-website-xrha.onrender.com

---

## 📌 Features

- 👤 User Registration & Login
- 🛍️ Browse Products
- 🛒 Add to Cart
- ➕ Update Cart Quantity
- ❌ Remove Products from Cart
- 💳 Checkout System
- 📱 Responsive User Interface
- 🔒 Django Authentication
- ⚡ Fast and Simple Navigation

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Tejapunnam/CodeAlpha-Ecommerce-Website.git
```

### 2️⃣ Move into the Project Folder

```bash
cd CodeAlpha-Ecommerce-Website
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Apply Database Migrations

```bash
python manage.py migrate
```

### 5️⃣ Start the Development Server

```bash
python manage.py runserver
```
