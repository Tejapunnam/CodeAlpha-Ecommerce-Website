# 🛒 CodeAlpha E-Commerce Website

A Django-based E-Commerce Website developed as part of the CodeAlpha Internship.

## 🚀 Features

- User Registration & Login
- Product Listing
- Shopping Cart
- Checkout System
- Responsive Design

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite

## ⚙️ Installation

```bash
git clone https://github.com/Tejapunnam/CodeAlpha-Ecommerce-Website.git

cd CodeAlpha-Ecommerce-Website

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
